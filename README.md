# Pirate Intelligent Agent Project

## Overview of My Work
For this project, I developed an intelligent agent to navigate a pirate treasure hunt scenario using reinforcement learning.

**Provided code:**  
- Basic maze environment with pirate positions, treasure locations, and game rules.

**My contributions:**  
- Designed and implemented a neural network model to estimate Q-values for actions.  
- Wrote the Q-learning training loop (`qtrain`) to train the agent over multiple epochs.  
- Implemented memory replay to stabilize learning and preserve past experiences.  
- Added an epsilon-greedy strategy to balance exploration and exploitation.

The agent learned optimal paths to the treasure while avoiding pirates, demonstrating practical reinforcement learning in a simulated environment.
